# Tricks

Copy [_template.md](_template.md) to start a new trick page.

A trick page has four parts:

- one line on what it does
- one code block to copy
- how to use it
- an example of the output

Put the page in a notebook under `tools/`. Use a lowercase file name with dashes. Example: `tools/cybersecurity/my-trick.md`.

If the trick needs a script, add the `.py` file under that notebook's `scripts/` folder.
