# Tricks

This folder is the catalog of agent tricks. Each trick is one folder.

```
tricks/
  _template/        copy this to start a new trick
  <trick-name>/
    README.md       required
    [TODO: other trick files]
```

## Rules

- Folder name: lowercase, with dashes.
- The README must have all template fields.
- Safety notes must be honest. If you do not know, write that.
