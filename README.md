# OpenKaipi

OpenKaipi is open-source agent tricks for any AI you use.

A trick is a prompt or a small script. You copy it from this repo. You do not install OpenKaipi.

## Notebooks

A notebook is a group of tricks for one job.

- [OpenKaipi Cybersecurity](tools/cybersecurity/README.md) — check a copy of your code, or a chatbot you own.

This is the only notebook right now.

## How to copy a trick

1. Open a notebook and choose a trick page.
2. Copy the code block on that page.
3. If it is a prompt, paste it into your AI.
4. If it is a script call, copy the script file the page names, then run the command.
5. Read "How to use it" on the same page.

To add a trick, copy [tricks/_template.md](tricks/_template.md). See [CONTRIBUTING.md](CONTRIBUTING.md) and the [Code of Conduct](CODE_OF_CONDUCT.md).
