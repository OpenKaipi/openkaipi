# Contributing

Thank you for helping. This project is built in public by students, so questions are welcome too.

## Add a trick

1. Fork the repo and make a new branch.
2. Copy `tricks/_template.md` to a new page. Use lowercase and dashes in the file name.
3. Put the page in a notebook under `tools/`. Example: `tools/cybersecurity/my-trick.md`.
4. Fill in the four parts: what it does, one code block to copy, how to use it, and an example of the output.
5. If the trick needs a script, add a `.py` file under that notebook's `scripts/` folder. Use Python 3.8 or newer and the standard library only. The file must run when someone copies it.
6. Open a pull request.

If you are not sure your idea is a good fit, open a "New trick" issue first.

## Other changes

- Bugs: open a "Bug report" issue.
- Ideas: open a "Feature request" issue.
- Small fixes (typos, docs): you can open a pull request directly.

## Pull request steps

1. One change per pull request. Small is better.
2. Fill in the pull request template.
3. Link the related issue if there is one.

## Review

- A maintainer reviews every pull request.
- For a trick, we check that the page is complete, the copy block works as written, and the steps are honest.
- Tricks that read private data, run code, or connect to other machines get a closer review.
- We may ask for changes. This is normal, not a rejection.
