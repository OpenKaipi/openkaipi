# Contributing

Thank you for helping. This project is built in public by students, so questions are welcome too.

## Add a trick

1. Fork the repo and make a new branch.
2. Copy `tricks/_template/` to `tricks/<your-trick-name>/`. Use lowercase and dashes in the name.
3. Fill in every field in the README: what it does, install, tested on, safety notes.
4. Add the trick files. [TODO: trick file format]
5. Test the trick with at least one AI app. Write which app and version in "Tested on".
6. Open a pull request.

If you are not sure your idea is a good fit, open a "New trick" issue first.

## Other changes

- Bugs: open a "Bug report" issue.
- Ideas: open a "Feature request" issue.
- Small fixes (typos, docs): you can open a pull request directly.

## Pull request steps

1. One change per pull request. Small is better.
2. Fill in the pull request template.
3. Link the related issue if there is one.
4. Make sure checks pass. [TODO: test and lint commands]

## Review

- A maintainer reviews every pull request. [TODO: who are maintainers, expected review time]
- For tricks, we check that the README is complete, the trick works as described, and the safety notes are honest.
- Tricks that handle private data, run code, or connect to remote machines get a closer review.
- We may ask for changes. This is normal, not a rejection.
